Administrator Access Role vs. Process Role — Decision Map

Which role type do you need?

Answer the questions below to find out whether you need an Access Role, a Process Role, or both — and where to set it up.

Step 1 of 3
What does this user need to do in C+R?
Start here — your answer will guide you to the right role type.
Step 2 of 3
Does an existing default access role fit their needs?
C+R ships with default roles like Administrator, Compliance Staff, Recruiting Staff, and Read-Only. These cover most use cases.
Step 2 of 3
Should this approval role apply to all sports or just specific ones?
Process roles can be scoped globally or limited to specific sports — useful when coaches or compliance staff oversee just one program.
✓ Use an Access Role
Assign a default access role to this user
Default access roles cover most staff configurations without any setup. Just assign the appropriate role during user creation or from their profile.
Where to do it: Settings → Security → Users → find the user → Edit → scroll to Access Roles → select the role → Save Changes.

Common default roles: Administrator · Compliance Staff · Recruiting Staff · Read-Only
✓ Create a Custom Access Role
Build a new access role with specific permissions
When no default role fits, create a custom access role and choose exactly which modules and features this user can access.
Where to do it: Settings → Security → Access Roles tab → Add Access Role → name it → click Edit → check each permission → Save.

Tip: You can remove permissions at any time by unchecking features and saving again.
✓ Use a Process Role — All Sports
Assign or create a process role scoped to all sports
This user will be an approver for the assigned workflows across every sport in your department.
Where to do it: Settings → Security → Process Roles tab → find or create the role → then go to the user's profile → add the process role → choose All Sports → Save.

Remember: Process roles control approval routing, not what the user can see. They may also need an access role.
✓ Use a Process Role — Sport-Specific
Assign a process role scoped to specific sports
This user will only receive workflow approvals for the sport(s) you select — ideal for sport-specific coaches or compliance coordinators.
Where to do it: Go to the user's profile → add the process role → when prompted, choose specific sports → select the relevant sport(s) → Save.

Remember: Process roles control approval routing, not what the user can see. They may also need an access role.
✓ You need both role types
Assign an Access Role AND a Process Role
Access roles control what a user can see and do. Process roles control which workflow approvals are routed to them. Most staff members who approve workflows need both.
Step 1 — Access Role: Settings → Security → Access Roles → assign or create a role that matches their module permissions.

Step 2 — Process Role: Go to the user's profile → add the relevant process role(s) → choose all sports or sport-specific → Save.

Example: A head coach might have the "Coach" access role (to see recruit and roster data) plus a "Head Coach" process role (to approve eligibility workflows for their sport).
